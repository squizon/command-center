How to install:

1 Look for the install icon in your browser's address bar — it looks like a monitor with a download arrow (⊕) or a small app icon
2 Click it and select "Install" when prompted
3 The Command Center will appear in your taskbar and Start menu — opens in its own window, no browser toolbar

Don't see the install icon? Try the browser menu (⋮) → "Install Command Center" or "Install app"

You can skip this and do it later — the option is always available in your browser.
